# 延伸示範 · 依規則新增法寶圖鑑

## 起點

先建立 AGENTS.md，再完成首頁、靈根系統、六大宗門、修煉境界和標準文章模板。基礎版本結構檢查通過，共 5 份 HTML（含模板）、102 個本地參照、3 筆搜尋索引。

## 實際執行

2026-11-04 重新讀取根目錄 AGENTS.md 後，依第 6 節執行下列擴充。

1. 檢查靈根、宗門及境界的既有設定，確認法寶品階為凡器、靈器、玄器。
2. 決定 slug 為 artifacts，主題為法寶圖鑑，分類為器物與共鳴。
3. 讀取 templates/article-template.html，用其完整 HTML 結構替換欄位，產生 pages/artifacts.html。保留麵包屑、文章標頭、卷內目錄、更新日期、正文、相關典籍及共用頁尾。
4. 沿用原有 style.css 和 site.js 的資訊卡、表格、FAQ 與搜尋邏輯。新增文章無須另一套樣式或互動腳本。
5. 在 catalog.js 加入法寶頁資料，首頁加入第四張靜態卡片、法寶分類按鈕與第四步閱讀路徑，分類總數由 03 改成 04。
6. 同步首頁、四篇文章及模板的主導覽，讓法寶在每頁都能直接到達。僅法寶頁的法寶連結帶 aria-current="page"。
7. 在宗門頁、境界頁加入法寶的相關典籍連結，法寶頁則連回三篇基礎典籍。
8. 執行結構與瀏覽器驗收，實際結果記入 CHANGELOG.md。

## 內容如何受到規則約束

四件法寶均記錄品階、關聯宗門、門檻、能力、限制。回潮鏡與鎮岳印需要築臺，九霄引雷環需要化神，與境界頁的門檻一致。引雷環最多暫存三道雷紋，失控時閉鎖，因此能力有可辨識的邊界。

## 可重複使用的部分

下一位 AI 只要讀 AGENTS.md，就能找到檔案位置、模板欄位、視覺規則、世界觀、導覽更新點、測試方法和日誌要求。再新增靈獸圖鑑時，可照同一流程建立文章、登錄搜尋索引並維持一致風格。

這次擴充的可核對證據包含實際法寶 HTML、模板、四筆 catalog.js 索引、首頁第四張卡片、兩篇舊文的反向連結，以及 CHANGELOG.md 的驗證紀錄。
